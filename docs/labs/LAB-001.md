# LAB-001 · Fundamentos de workspaces y recursos en la nube

**Nivel:** inicial · **Duración estimada:** 30 min · **Prerrequisitos:** ninguno

Aprenderás a organizar recursos dentro de un workspace:

- Crear almacenamiento y lakehouse.
- Configurar el nivel de acceso y la redundancia.
- Etiquetar recursos para organizarlos.
- Eliminar los recursos que ya no se usan, observando su ciclo de vida.

**Objetivos**
- Entender qué es un workspace y por qué agrupa recursos.
- Crear recursos de almacenamiento y lakehouse.
- Configurar el nivel de acceso y la redundancia de un almacenamiento.
- Usar etiquetas para organizar recursos.
- Eliminar recursos que ya no se necesitan.

**Evaluación:** 4 ejercicios (100 puntos). Se comprueba el estado real del workspace del laboratorio. Las pistas restan puntos.
