# M10b: Course modules, lessons and notifications (release 1.2)

Granular breakdown written before starting, as master plan §29 requires. It extends the minimal courses of M10a (`docs/architecture/COURSES.md`): master plan §18 lists "modules and lessons (CommonMark content), publishing, due dates, notifications" for release 1.2.

## Concepts

- **Module:** an ordered section of a course (title, summary, `draft|published`).
- **Lesson:** an ordered page inside a module, with the following fields:
  - a title and a CommonMark body, rendered server-side with raw HTML escaped and unsafe links dropped;
  - estimated minutes;
  - an optional due date;
  - an optional link to a lab already assigned to the course;
  - a status, `draft` or `published`.
- **Visibility:**
  - Staff (owner, enrolled instructors, tenant-wide roles) see everything.
  - An enrolled student sees a lesson only when the course is not a draft and both its module and the lesson are published. Anything else answers **404**, the same as an object that does not exist.
- **Progress:** a student marks a lesson as completed, and can undo it. The progress grid adds "lecciones completadas / publicadas" per student.
- **Notifications (in-app):**
  - Events:
    - a lesson becomes visible (published in a published module of a non-draft course);
    - a lesson or a course lab is due within 24 h and the student has not completed it (sent by the scheduler, once).
  - One row per user and event, deduplicated by `(user_id, kind, ref_key)`.
  - Shown in a top-bar bell with an unread count; they can be marked as read and are purged 90 days after being read.
  - Links are server-generated app paths.

## Non-goals (later releases)

- E-mail notifications and per-user notification preferences (in-app only for now).
- Instructor-authored labs through the UI (labs stay declarative files imported by CLI, ADR-008).
- Quizzes, file attachments in lessons, drip/schedule-based unlocking and certificates.

## Risks

| Risk | Mitigation |
|---|---|
| Stored XSS through lesson Markdown | CommonMark with `html_input: escape` and `allow_unsafe_links: false` (same converter as the lab instructions); an XSS payload test on the rendered page. |
| Students reading drafts or other courses' lessons | Visibility enforced in one repository query (enrollment + statuses); isolation matrix and role tests. |
| Notification spam / table growth | Dedupe key, triggers only on visibility transitions, purge of read notifications, list capped at 50. |
