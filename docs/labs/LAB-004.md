# LAB-004 · Construye un data lake

**Nivel:** inicial · **Duración estimada:** 40 min · **Prerrequisitos:** LAB-001

Recorrerás el camino de los datos de la capa **raw** (archivos tal como llegan) a la capa **bronze** (tablas consultables):

1. Subir un CSV de clientes y revisar el esquema que se detecta.
2. Crear un lakehouse.
3. Ingerir el archivo como tabla.
4. Explorar con SQL la calidad de los datos.

**Evaluación:** 4 ejercicios (100 puntos). Se comprueban el dataset raw, la tabla bronze (columnas, tipos y filas) y una consulta de exploración.
