# LAB-003 · Fundamentos de SQL analítico

**Nivel:** inicial · **Duración estimada:** 60 min · **Prerrequisitos:** ninguno

Son ocho ejercicios progresivos sobre los datos de ventas de una cadena de tiendas ficticia: filtros, ordenación, JOIN, GROUP BY/HAVING, CTE, subconsultas, funciones de ventana y fechas. El laboratorio prepara un lakehouse con las tablas en la capa bronze.

Cada respuesta es una consulta SQL. El servidor la vuelve a ejecutar en un entorno aislado y compara su **resultado** con el esperado. La forma de escribirla es libre.

**Evaluación:** 8 ejercicios (100 puntos). Las pistas restan puntos.
